# MPhil-Thesis
Developing a Portfolio Management Approach to PPPs

This research advocates for increased use of Public-Private Partnerships to deliver infrastructure in Ireland. It recommends a portfolio management approach to ensure fiscal control. A synthetic portfolio is constructed, to demonstrate modelling practices and account for correllated risk.

Content:
1. <b>Portfolio Management of PPPs.pdf</b>: Report file
2. <b>PFRAM_Synthetic_Modelling.xlsm</b>: Main modelling file
3. <b>PFRAM_Synthetic_Modelling.xlsm</b>: Stochastic modelling layer
